# Song Ambient icon provenance

Generated using the built-in image generation tool for this project. The PNG is the source artwork; `.icns` and iconset sizes were packaged with Apple's `sips` and `iconutil`. The monochrome menu bar orbit is a newly drawn template image in `Windows.swift` and matches the in-app `OrbitMark`.

Prompt:

> Use case: logo-brand. Asset type: production macOS application icon for Song Ambient, a music-reactive edge-lighting and constellation lyrics app. Create one polished 1024x1024 square icon. A bold, minimal continuous luminous orbital S-shaped audio ribbon, with one small star/node at its tip, centered on a deep midnight indigo squircle. Cyan-to-electric-violet-to-warm-magenta iridescent light, controlled subtle bloom, crisp silhouette, generous negative space. Premium native macOS icon, sculpted glass depth but clean and readable at tiny sizes, front view. No text, no letters, no music-note glyph, no extra objects, no mockup, no outer scene. The squircle fills 90% of the square and the outside corners are transparent.
